# Sistema de Mascotas
## Descripción

Programa en Python que utiliza Programación Orientada a Objetos para simular mascotas y su nivel de felicidad.
Las mascotas pueden alimentarse y jugar, lo que aumenta su nivel de felicidad.

*Funcionamiento*

La clase Mascota tiene los atributos:

nombre

tipo

edad

nivelFelicidad

*Métodos principales:*

alimentar() → aumenta la felicidad.

jugar() → aumenta la felicidad.

es_feliz() → indica si la mascota es feliz (felicidad ≥ 70).

*Ejecución*

El programa crea dos mascotas y muestra cómo cambia su nivel de felicidad después de alimentarlas y jugar con ellas.

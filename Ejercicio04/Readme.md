# Sistema de Aventureros en Python

## Descripción
Este proyecto consiste en un programa desarrollado en **Python** donde se aplica **Programación Orientada a Objetos (POO)** para representar personajes de un mundo de fantasía.  

Se crean distintos tipos de aventureros, cada uno con características y habilidades propias, mostrando cómo funcionan conceptos como **clases, objetos y herencia** dentro de un programa.

## Objetivo de la actividad
El propósito de la actividad es practicar la organización del código y el uso de la **herencia y los métodos en Python**, permitiendo que diferentes tipos de personajes compartan una estructura común pero tengan comportamientos específicos.

# Sistema de Cuenta Bancaria
## Descripción

Programa en Python que utiliza Programación Orientada a Objetos (POO) para simular el funcionamiento básico de una cuenta bancaria, permitiendo realizar depósitos, retiros y consultar el saldo.

*Funcionamiento*

La clase CuentaBancaria contiene los atributos:

titular

numeroCuenta

saldo

*Métodos principales:*

ingresar() → permite depositar dinero en la cuenta.

retirar() → permite retirar dinero si hay saldo suficiente.

mostrar() → muestra la información de la cuenta.

*Ejecución*

El programa crea una cuenta bancaria, realiza un depósito, un retiro y finalmente muestra el saldo actualizado.

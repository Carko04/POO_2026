# Animales con Clases Abstractas
## Descripción

Programa en Python que utiliza Programación Orientada a Objetos y clases abstractas para representar diferentes tipos de animales y el sonido que hacen.

*Funcionamiento*

Se define una clase abstracta Animal que contiene el método abstracto hablar().
Las clases Perro y Gato heredan de Animal e implementan este método.

*Ejecución*

El programa crea un Perro y un Gato, y muestra el sonido que hace cada uno.

''' Ejemplo de salida:

Woof!
Meow! '''

*Conceptos utilizados*

Clases abstractas

Herencia

Polimorfismo
